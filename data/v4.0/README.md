# Bộ dữ liệu giải đoán Tử Vi Đẩu Số v4.0 (bản nén theo năm)

Bản sao 77 file nén `year-YYYY.jsonl.zst` (năm 1950–2026), 674.976 lá số × 13 phương diện.
Giải nén: `zstd -d --long=27 year-YYYY.jsonl.zst` (mỗi năm khoảng 740 MB sau khi giải nén).
Kiểm tra toàn vẹn bằng sha256 trong `MANIFEST.json`.
